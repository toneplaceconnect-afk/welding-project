### Что ещё можно добавить крупного (металл + дерево), исходя из спроса в регионе

Смотрел, чем закрывают спрос смежные ниши в Абакане (мебель на заказ — 5+ активных студий, кухни/шкафы-купе — насыщенный рынок, туда лезть не стоит; но эти сегменты **не** заняты на стыке металл+дерево):

Ниша свободна: барные стойки, стеллажи для витрин, столы и стулья на сварном каркасе для HoReCa — B2B-чек выше, повторные заказы (сети кафе).
2. **Беседки, перголы, навесы-беседки (металл+дерево)** — уже подтверждено ЭкоЛОФТ как категория, но с учётом сурового климата Хакасии (снеговая нагрузка) — усиленный металлокаркас с деревянной обшивкой продаётся как «то, что не сломается зимой», это ваше УТП против чисто деревянных беседок.
3. **Лестницы на металлокосоуре с деревянными ступенями** — уже есть локальный игрок (steel_inox: лестница под ключ ≈70 000₽/шт, перила из нержавейки 2000–4000₽/п.м) — но именно дерево+металл комбинация (не нержавейка) — открытая ниша, дешевле в материале, лофт-эстетика в тренде.
4. **Мангальные зоны / уличные кухни под ключ (каркас+столешница+навес)** — сезонный, но высокочековый продукт (частный сектор Хакасии — много участков с домами), логично продолжает «навесы/ворота».
5. **Стеллажи и системы хранения для гаражей/мастерских (металл+фанера/OSB)** — низкий чек, но простой в производстве и хорошо продаётся как допродажа к любому основному заказу (клиент уже ставит забор — предложить стеллаж в гараж).
6. **Барные стойки и ресепшн-стойки для коммерческих помещений (металл+дерево/массив)** — B2B-сегмент, не встречен явно в выдаче конкурентов Абакана → вероятно свободная ниша, но статус **HYPOTHESIS**, не проверено напрямую (не нашёл прямого отрицания или подтверждения спроса).

**Не рекомендую добавлять:** корпусную мебель (кухни, шкафы-купе, спальни) — это переполненный рынок минимум 5 активных студий в Абакане (abakan_mebel и клоны, mebel-abakan24 и т.д.), там вы не сварщик-инженер, а прямой конкурент мебельным цехам без вашего УТП.

## 0.2 РЕШЕНИЕ ВЛАДЕЛЬЦА (зафиксировано, приоритет выше моих рекомендаций по прайсу)

- Корпусная мебель (кухни, шкафы-купе) — **точно исключена** из услуг. Подтверждено.
- **Структура сайта меняется:** главная страница — без единой цены нигде. Прайс выносится на отдельную страницу.
- Лофт-мебель (металл+дерево) — тоже отдельная страница, но **без фиксированных цифр** — везде «цена по договорённости».
- **Временное решение:** пока прайс-страница остаётся пустой / со статусом «по договорённости» по всем позициям (включая заборы, отопление, металлоконструкции — не только мебель). Числовые ориентиры из разделов 1 и 0.1 этого документа **не публикуются на сайте** — это только моя внутренняя расчётная база для вас, к структуре страниц не привязана. Вернёмся к наполнению прайса, когда будет отдельная команда.
- Соответственно калькулятор (раздел 2) на первом этапе выводит **не число**, а формулировку: «Точную стоимость назову после уточнения деталей / бесплатного замера» — жёсткая вилка ₽ пока не показывается публично, хотя логика расчёта (формулы) остаётся готовой для внутреннего использования и для последующего включения на сайт.

Итого структура сайта: Главная (без цен, УТП «дешевле региона на 15%» упоминается текстом, но без конкретных цифр на витрине) → Страница «Прайс» (по договорённости, пусто/заглушка) → Страница «Лофт-мебель» (галерея + «цена по договорённости») → **Страница «Документация» (см. раздел 6 ниже — СП/ГОСТ по разделам)** → Форма заявки/калькулятор (собирает данные, не выдаёт цену).

## 2. Логика калькулятора (для последующей реализации в коде)

Три отдельных под-калькулятора внутри одной формы (переключаются табами/select), результат — **не окончательная цена, а вилка + заявка**, чтобы не подставляться под фиксированную оферту без замера.

### 2.1 Калькулятор металлоконструкций (заборы/ворота/навесы/лестницы)
Входные поля:
- Тип конструкции (select): забор / ворота / навес / лестница / другое
- Длина/периметр, м (number)
- Высота, м (number)
- Тип заполнения (select): профлист / евроштакетник / сетка-рабица / кованые элементы / без заполнения (каркас)
- Наличие материала (radio): всё есть / нужно закупить / помочь с закупкой

Формула вывода (ориентировочная вилка, не окончательная цена):
```
материал_метр = БАЗА[тип_трубы] × наценка_1.10
работа_метр   = 2518 ₽ (база) … 3647 ₽ (премиум-каркас)
итого_вилка   = периметр × (материал_метр + работа_метр) ± 15%
```
Вывод: «Ориентировочно от **X ₽** до **Y ₽**. Точная цена — после бесплатного замера.»

### 2.2 Калькулятор отопления/водоснабжения
Входные поля:
- Площадь объекта, м² (number)
- Тип объекта (select): новый дом / замена старой системы / коттедж 2 этажа
- Есть ли котёл/радиаторы (radio): всё закуплено / нужно подобрать
- Тип системы (select): радиаторное / тёплый пол / комбинированное

Формула вывода:
```
база_монтажа = 2125–4250 ₽ (выезд+база)
тёплый_пол   = площадь × 298 ₽ (если выбран)
итого_вилка  = база_монтажа + тёплый_пол + (расходники по смете после замера)
```

### 2.3 Калькулятор дизайнерских предметов (мебель металл+дерево)
Входные поля:
- Тип изделия (select): стол / стеллаж / скамья / диван / барная стойка / беседка-навес / лестница / другое (описать)
- Габариты, см (ШxГxВ, три поля number)
- Материал столешницы/сиденья (select): массив сосны / дуб / фанера/мебельный щит / металл
- Покрытие металла (select): порошковая окраска RAL / без покрытия

Формула вывода (вилка от готовых изделий-аналогов, скорректированная -15%):
```
база_по_типу = ТАБЛИЦА[тип_изделия] × 0.85   # из прайса раздела 0.1
корректировка_габаритов = база × (площадь_факт / площадь_эталон)
итого_вилка = корректировка_габаритов ± 20%   # мебель более штучная, вилка шире
```
Вывод: «Ориентировочно от **X ₽**. Финальная цена — после эскиза и согласования материала.»

### Расчёт №1 — Забор из профнастила (профильная труба на столбы + лаги + профлист + крепёж)

**Входные поля:**
- Длина забора (периметр), м — *number*
- Высота забора, м — *select: 1.5 / 1.8 / 2.0 / 2.2 / 2.5*
- Марка профнастила — *select: С8 (1150) / С20 (1100) / С21 (1000) / своя ширина (number, мм)*
- Тип грунта — *select: песчаный/каменистый (лёгкий) / суглинок-глина (пучинистый, требует запаса)*
- Сечение трубы на столбы — *select: 60×60 / 80×80 (для высоких/ветреных участков)*
- Сечение трубы на лаги — *select: 40×20 / 40×25*
- Ворота — *количество (0/1/2…), ширина проёма каждого, м*
- Калитка — *количество (0/1/2…), ширина проёма, м*

**Формулы (последовательно):**

```
# 1. Столбы
шаг_столбов = ЕСЛИ высота > 2.2 ИЛИ грунт=пучинистый → 2.0…2.5 м
              ИНАЧЕ → 2.5…3.0 м
N_столбов_линия = ROUND_UP(периметр / шаг_столбов) + 1
N_столбов_ворота = количество_ворот × 2   (усиленные, сечение крупнее)
N_столбов_калитка = количество_калиток × 1   (со стороны замка; вторая опора часто общая со столбом линии)

# 2. Длина трубы на столбы
заглубление = MAX(высота / 3, запас_по_грунту)
  где запас_по_грунту = 1.0 м (лёгкий грунт) / 1.5 м (пучинистый грунт — консервативно, до уточнения по СП)
длина_1_столба = высота + заглубление + 0.05 (запас на подрезку/оголовок)
общая_длина_трубы_столбы = (N_столбов_линия × длина_1_столба) 
                          + (N_столбов_ворота × (высота + заглубление_усилен + 0.05))
                          + (N_столбов_калитка × длина_1_столба)

# 3. Лаги (прожилины)
количество_рядов_лаг = ЕСЛИ высота ≤ 1.5 → 2
                        ЕСЛИ 1.5 < высота ≤ 2.2 → 2
                        ЕСЛИ высота > 2.2 → 3
общая_длина_трубы_лаги = периметр × количество_рядов_лаг × 1.05   # 1.05 = запас на нахлёст/подрезку в стыках

# 4. Профнастил
рабочая_ширина_листа = ЗНАЧЕНИЕ[марка_профнастила]   # 1.15 / 1.10 / 1.00 (в метрах)
количество_листов = ROUND_UP(периметр / рабочая_ширина_листа)
площадь_листа = рабочая_ширина_листа × высота
общая_площадь_профнастила = количество_листов × площадь_листа

# 5. Саморезы
саморезы_на_лист = 4 × количество_рядов_лаг + 2
общее_число_саморезов = саморезы_на_лист × количество_листов

# 6. Ворота/калитка отдельно (упрощённо, как доп. блок)
труба_на_раму_ворот = (2×высота + 2×ширина_проёма) × количество_ворот   # периметр рамы створки
петли_ворота = 3 шт/створка (усиленные)
профнастил_на_створку = площадь_створки / рабочая_ширина_листа  → отдельные листы (либо подрезка от общего числа)
```

- Вход: площадь помещения, высота потолков, тип утепления (норма Вт/м²) → расчёт требуемой мощности радиаторов (секции) по норме (обычно 100 Вт/м² для стандартного утепления Сибири, это тоже норматив, который нужно подтвердить отдельным запросом, если пойдём в эту секцию).

Помечаю как **следующий этап** — если хотите такой же по строгости калькулятор для отопления, лучше сделать отдельным запросом (там другой набор нормативов — теплотехника, а не строймонтаж заборов, точность требует отдельной проверки СП по отоплению).

### A. Металлоконструкции — полный список категорий (материалы, не цена)

Помимо забора (раздел 2bis), логика «периметр/площадь → метраж трубы + крепёж + расходники» одинаково применяется к:

| Изделие | Что считает калькулятор |
|---|---|
| **Навес/козырёк** (профлист или поликарбонат на металлокаркасе) | Площадь ската → кол-во листов поликарбоната/профнастила (по рабочей ширине) + метраж трубы на стропила/обрешётку (шаг обрешётки зависит от типа кровли: поликарбонат — 0,7–1 м, профнастил — до 1,5 м) + метраж опорных стоек (по высоте+заглубление, как в разделе 2bis) + саморезы/термошайбы (для поликарбоната — термошайбы, не обычный саморез — отдельная норма расхода) |
| **Ворота/калитка** (отдельно, не только довесок к забору) | Периметр рамы створки → труба на раму + диагональные усилители (по площади створки, если >6 м²) + петли (2–3 шт/створка, тяжёлые — 3) + автоматика (опционально, отдельным полем — не материал, а комплектующая единица) |
| **Лестница металл+дерево** (косоур + деревянные ступени) | Высота этажа, угол наклона → количество ступеней (шаг 15–20 см) → метраж трубы на косоур(ы) (2 боковых или 1 центральный) + количество деревянных проступей (доска/массив, по ширине марша) + метраж трубы на перила/балясины + крепёж (болты М8-М10 на ступень, 2-4 шт) |
| **Перила/ограждения** (лестничные, балконные) | Погонный метр → стойки (шаг 1–1,2 м) + поручень (метраж = периметр) + заполнение (балясины шт/м либо лист) |
| **Мангальная зона/уличная кухня под ключ** | Площадь столешницы + периметр каркаса → труба на каркас + лист металла на столешницу (толщина от 3мм для открытого огня) + огнеупорная обшивка (кирпич/плитка — кв.м) |
| **Стеллаж гаражный (металл+фанера/OSB)** | Габариты (Ш×Г×В), кол-во полок → метраж трубы на стойки/полки + лист фанеры/OSB на полки (по площади, с учётом стандартного листа 1,22×2,44 м) + крепёж уголками |

### Б. Мебель металл+дерево (материалы, не только цена — уточнение к разделу 0.1/2.3)

Для каждого изделия (стол, скамья, барная стойка, стеллаж) калькулятор считает не итоговую цену, а:
- метраж трубы на каркас (по периметру опор + перемычки жёсткости)
- площадь и объём древесины на столешницу/сиденье (доска/массив/мебельный щит — по толщине и площади)
- крепёж (уголки, конфирматы/мебельные стяжки — количество по числу соединений)
- порошковая окраска металлокаркаса (расход по площади поверхности трубы, не по площади проекции)

### В. ОТОПЛЕНИЕ — полная система (материалы)

**Входные поля:**
- Общая отапливаемая площадь дома, м² + этажность
- Высота потолков, м (влияет на объём, а не только площадь)
- Количество и площадь каждой комнаты (для точного расчёта радиаторов по комнатам, не «в среднем по дому»)
- Тип котла: газовый / твердотопливый / электрический
- Нужен ли контур ГВС от котла (да/нет)
- Тип разводки: однотрубная / двухтрубная / коллекторная (лучевая)
- Материал труб: полипропилен / металлопластик / медь

**Формулы:**

```
# 1. Мощность котла
УМК = 1.5…2.0 кВт/10м²   # северный регион (Хакасия), см. таблицу выше
мощность_котла = (площадь_дома / 10) × УМК
ЕСЛИ нужен_ГВС → мощность_котла × 1.25

# 2. Радиаторы — ПОКОМНАТНО, не одной цифрой на весь дом
ДЛЯ каждой_комнаты:
    требуемая_мощность = площадь_комнаты × 100 Вт/м²
    N_секций = ROUND_UP(требуемая_мощность / мощность_1_секции[тип_радиатора])
    # мощность_1_секции: алюминий/биметалл ≈ 180 Вт, чугун ≈ 160 Вт (типовые паспортные значения)
ИТОГО_секций_по_дому = СУММА(N_секций по всем комнатам)

# 3. Трубы (метраж)
ЕСЛИ разводка = коллекторная:
    метраж_трубы = СУММА(расстояние_от_коллектора_до_каждого_радиатора × 2 (подача+обратка)) × 1.15 (запас на повороты)
ИНАЧЕ (одно/двухтрубная):
    метраж_трубы = периметр_дома × этажность × коэфф_обвязки(1.3…1.5) × (1 или 2, по типу системы)

# 4. Расширительный бак
объём_системы ≈ метраж_трубы × ёмкость_1м_трубы[диаметр] + объём_котла + объём_радиаторов(секция≈0.3-1.4л по типу)
объём_бака = объём_системы × 0.10…0.12

# 5. Насос циркуляционный — подбор по расходу, не по материалу (комплектующая единица, не считается в метрах)

# 6. Запорная арматура (шаровые краны, термоголовки)
N_кранов = 2 × количество_радиаторов (подача+обратка на каждый) + N_на_коллекторе (если коллекторная)
N_термоголовок = количество_радиаторов (опционально, если нужна поштучная регулировка)
```

**Вывод клиенту (без цены):**
> «Для дома [S] м² потребуется: котёл ~[N] кВт, радиаторов — [N] секций (с разбивкой по комнатам), труба [материал] — [N] м, расширительный бак [N] л, кранов запорных — [N] шт. Точная комплектация и стоимость — после теплотехнического расчёта на объекте (обязателен из-за индивидуальных теплопотерь дома).»

### Г. ВОДОСНАБЖЕНИЕ — полная система (материалы)

**Входные поля:**
- Источник: скважина / колодец / центральный водопровод
- Количество точек водоразбора (краны, смесители, стиральная/посудомоечная машина, унитазы)
- Этажность
- Нужен водонагреватель (да/нет, тип: накопительный/проточный)
- Нужна фильтрация (грубая/тонкая/умягчение — да/нет)

**Формулы (по методике, аналогичной найденному международному калькулятору сантехники — адаптировано под метры и наши материалы):**

```
метраж_трубы = СУММА(среднее_расстояние_от_ввода_до_точки × количество_точек) × 1.15 (запас)
диаметр_магистрали = 25-32 мм (для дома до 10 точек разбора), 32-40мм (>10 точек)
диаметр_отвода = 16-20 мм на каждую точку

N_фитингов (тройники/уголки) ≈ количество_точек × 2.5 (эмпирический коэфф. на разводку, включая повороты)

насосная_станция: подбор по производительности (не материал, комплектующая единица) — по числу точек и одновременности разбора
гидроаккумулятор: объём по количеству точек (обычно 20-24л на дом до 5 точек, 50-100л — от 5-10 точек)

фильтры: грубая очистка — 1 шт на ввод; тонкая/умягчение — по числу ступеней, каждая отдельная колба
водонагреватель: подбор по объёму (накопительный, л) от количества проживающих × 30-50л/чел, либо проточный по мощности (кВт) от макс.одновременного разбора
```

Сами числовые значения по месяцам через веб-поиск извлечь не удалось (страница требует прямого/JS-рендера) — **это сузившийся, но не полностью закрытый GAP**: источник и точный документ известны, конкретные цифры нужно снять один раз с этой страницы (или из PDF СП 131.13330.2025) при кодировании калькулятора — 10 минут работы, не догадка.
