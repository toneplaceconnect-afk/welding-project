# Фото сайта

Чтобы заменить фото — положите свой файл на место существующего,
**сохранив имя и расширение** (`.webp`). Можно и `.jpg`/`.png` — тогда
поправьте расширение в пути внутри страницы.

Рекомендуемый размер: длинная сторона 1200–1600 px.

но тогда оно сохранится отдельно от этих файлов.
