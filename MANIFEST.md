# ПРОЕКТ-СВАРКА — манифест готовности

Дата: 2026-09-14

## Исправлено

- Единый стандарт написания бренда: `ПРОЕКТ-СВАРКА` — без пробелов вокруг дефиса.
- Единый brand-markup для названия в общей шапке и футере: один DOM-шаблон, один шрифт Michroma, один кегль 14px, один вес 700.
- Страница `create.html` больше не должна иметь отдельную визуальную реализацию футера: общий `site-header.js` заменяет её локальный footer на общий site-footer и применяет тот же брендовый markup.
- Общая шапка задаётся через `site-header.js`; на `create.html` она использует тот же шаблон, что и на DC-страницах.
- Мобильная иконка телефона в общей шапке использует `tel:+79831981588` и открывает системное действие звонка, а не Telegram.
- Телефонная ссылка в `create.html` также использует `tel:`.
- На странице «Создай своё» шапка фиксируется сверху при прокрутке на мобильных устройствах.
- Кнопка «Наверх» вынесена из динамического контейнера и имеет единый обработчик прокрутки.
- Исправлена логика MutationObserver: общий footer не удаляется повторно при каждой DOM-мутации.
- Динамические DC-страницы имеют резервный режим отображения при недоступности CDN React, чтобы не превращаться в белый экран.
- В `vercel.json` сохранена маршрутизация корня сайта на главную страницу и редирект старого URL «Создай своё».

## Ключевые файлы

- `site-header.js` — единый источник shared chrome: шапка, footer для Create, телефон, мобильное меню, кнопка «Наверх», брендовый markup.
- `site-header.css` — базовые стили общей шапки.
- `create.html` — содержимое конструктора; его chrome нормализуется общим UI-скриптом.
- `support.js` — устойчивый bootstrap DC-runtime.
- `support-runtime.js` — текущий сгенерированный DC runtime.
- `vercel.json` — маршрутизация Vercel.
